# Project Rules

## Stack
- React JSX, not TSX
- Vite
- Tailwind CSS
- Axios
- React Router
- Node.js + Express

## Coding Rules
- Reuse existing components before creating new ones.
- Never change API contracts without checking backend routes.
- Never create duplicate API functions.
- Use existing utils/api.js.
- Keep responsive mobile/tablet/desktop layouts.
- Check existing folder structure before creating files.

## Before Coding
1. Inspect relevant files.
2. Understand existing architecture.
3. Find existing API functions.
4. Check related components.
5. Make the smallest safe change.

## After Coding
1. Run lint.
2. Run build.
3. Check imports.
4. Check API paths.
5. Report changed files.
